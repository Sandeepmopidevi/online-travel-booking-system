# Stayora: Online Travel and Hospitality Booking System

Stayora is a web application designed to make booking hotels, flights, and travel packages easy and convenient. It’s built so that people can plan their entire trip in one place, whether they want to book a hotel for a night, fly to another city, or choose a full travel package. The project is organized around four main types of users: Admin, Traveller, Hotel Manager, and Travel Agent. Each role gets its own unique set of features and can only see or do what’s meant for them.

The **Admin** is the main manager in Stayora. Admins can create, edit, delete, and view hotels, flights, travel packages, and reviews. If a user has a problem and submits a support ticket, the admin can assign it to the right person and follow up. Admins can also send emails to users, for example to confirm bookings or resolve issues.

The **Traveller** is an everyday user who wants to book a trip. Travellers can book hotels, flights, and packages, make payments online, and download their invoices as PDF files. If they want, they can create a custom travel plan called an itinerary. If they face a problem, they can raise a support ticket or contact the admin directly for help.

The **Hotel Manager** is responsible for managing hotel information. They can add new hotels, update details, or remove hotels from the site. They can also see ratings and reviews from travellers who have stayed at their hotels. If they need help, they can contact the admin as well.

The **Travel Agent** has special tools to create custom itineraries for travellers. If a traveller wants a special trip or tour, the agent can plan it all for them. Travel agents can also reach out to admins if they run into any problems.

Stayora is smart about what it shows to users. When someone logs in, the website checks their role and only shows the features that are meant for them. For example, only admins see the options to delete hotels or assign support tickets, while a traveller will only see options to book, pay, or get help. This makes the website simple and safe for everyone.

What makes Stayora stand out is how everything is in one place. It combines bookings, payments, custom trip planning, support tickets, and reviews in a single, easy-to-use system. If a traveller has a problem, they can quickly get help. If a manager needs to update hotel info, they can do it easily. And because the system is role-based, it is secure and user-friendly.

When talking to an interviewer, explain it like: “Stayora is a beginner-friendly travel booking website with different user roles. Admins manage everything, travellers book and get support, hotel managers handle hotels, and travel agents plan special trips. The system is easy to use, only shows people what they need, and lets everyone get help if they need it. It’s a practical and real-world project that shows how to build secure, role-based web applications.”

In short, Stayora is a travel booking system where people see only what they need, can get support easily, and manage all their travel plans in one place.
